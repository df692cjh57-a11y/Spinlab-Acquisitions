bank_monthly_debt_service + seller_financing_monthly_payment

Annual Debt Service =
total_monthly_debt_service * 12

primary_adjusted_sde - annual_debt_service

Monthly Cash Flow After Debt =
cash_flow_after_debt / 12

DSCR =
primary_adjusted_sde / annual_debt_service

Cash-on-Cash Return =
cash_flow_after_debt / total_cash_needed

Debt Yield =
primary_adjusted_sde / loan_amount

Loan-to-Value / LTV =
loan_amount / purchase_price

Break-even Revenue =
total_operating_expenses + annual_debt_service

Break-even Revenue % of Current Revenue =
break_even_revenue / gross_revenue

Debt Service % of Gross =
annual_debt_service / gross_revenue

Monthly payment formula:

Monthly Payment =
P * [r(1+r)^n] / [(1+r)^n - 1]

Where:
- P = principal
- r = monthly interest rate
- n = number of monthly payments

If interest rate is 0:
Monthly Payment = principal / n

If principal is 0:
Monthly Payment = 0

If amortization years is 0 or missing:
Monthly Payment should return null unless principal is 0.

If DSCR < 1.25:

If DSCR < 1.10:
“High risk: deal may not support debt.”

If cash_on_cash_return < 0:
“Negative cash flow after debt.”

If cash_on_cash_return > 0 and cash_on_cash_return < 0.10:
“Low cash-on-cash return relative to acquisition risk.”

If total_cash_needed > purchase_price * 0.25:
“High cash requirement.”

If debt_service_percent_gross > 0.25:
“Debt service consumes more than 25% of revenue.”

“Price may be workable.”

If asking_price is 0% to 15% above suggested_offer:
“Negotiate. Gap is not impossible.”

If asking_price is 15% to 35% above suggested_offer:
“Large pricing gap. Needs seller financing, price reduction, or major verified upside.”

If asking_price is more than 35% above suggested_offer:
“Likely overpriced unless seller numbers are proven or upside is exceptional.”

If primary adjusted SDE is missing:
“Not enough data to recommend an offer.”

Display:
- suggested multiple
- suggested offer
- asking price
- offer gap
- recommendation
