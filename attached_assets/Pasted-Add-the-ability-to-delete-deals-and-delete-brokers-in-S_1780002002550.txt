Add the ability to delete deals and delete brokers in Spinlab Deal Desk.

Do not rebuild the app from scratch.
Do not remove existing features.
Keep the current clean Apple/Tesla-style design.

Goal:
Users should be able to safely delete deals and brokers without breaking linked data.

--------------------------------
1. DELETE DEALS
--------------------------------

Add delete functionality for deals.

Places where delete should appear:
- Deals table row action menu
- Deal detail page
- Bulk selected deals action

Use soft delete first.

Add these fields to the deals table/model if they do not already exist:

- deleted_at
- archived_at

When a deal is deleted:
- set deleted_at to the current timestamp
- hide it from the main Deals page
- hide it from active dashboard metrics
- do not permanently remove it from the database

Add a confirmation modal before deleting.

Modal title:
Delete deal?

Modal body:
This will move the deal to Deleted Deals. You can restore it later from Settings.

Show in the modal:
- Deal name
- Address
- Asking price
- Linked broker, if any

Buttons:
- Cancel
- Archive instead
- Delete deal

Delete button should be red.
Archive should be the safer secondary option.

--------------------------------
2. DELETED DEALS VIEW
--------------------------------

In Settings, add a section called:

Deleted Deals

Show all soft-deleted deals.

For each deleted deal, allow:
- Restore deal
- Permanently delete deal

Restore deal:
- clear deleted_at
- return deal to main Deals page

Permanent delete:
- require a second confirmation modal

Permanent delete modal:

Title:
Permanently delete deal?

Body:
This action cannot be undone.

Buttons:
- Cancel
- Permanently delete

Only permanently delete after confirmation.

5. BROKER DELETE SAFETY
--------------------------------

Before deleting a broker, check if the broker has linked deals.

If the broker has no linked deals:
- show normal delete confirmation

Modal title:
Delete broker?

Modal body:
This will move the broker to Deleted Brokers. You can restore it later from Settings.

Buttons:
- Cancel
- Archive instead
- Delete broker

If the broker has linked deals:
Show a stronger confirmation modal.

Modal title:
Delete broker?

Modal body:
This broker is linked to X deals. Deleting the broker will not delete those deals. Choose what you want to do.

Options:
1. Cancel
2. Archive broker instead
3. Remove broker from linked deals and delete broker
4. Reassign linked deals to another broker

Important:
- Never delete linked deals when deleting a broker.
- If removing broker from deals, set broker_id to null on those deals.
- If reassigning, allow user to pick another broker from a dropdown.
- After reassignment, soft delete the broker.

If a deal has no broker after deletion, show:
No broker assigned
